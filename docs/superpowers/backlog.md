## Дрібниці (можуть почекати)
- Guard-и не повторюють завантаження сесії самі, коли стан «невідомий» (є банер із кнопкою «Спробувати ще раз»).
- `returnTo` губиться для pending-користувача після завершення профілю.
- 401 при перезавантаженні після `identity.linked` лишає користувача на `/account`.
- Дві паралельні OAuth-сесії в одному браузері — перша падає (одна кука `nri_oauth`).
- Немає тесту на пропуск rate limit для запитів з валідним внутрішнім ключем.
- Graceful shutdown не обриває «зависані» keep-alive з'єднання.
- `updated_at` оновлюється лише через Drizzle, без `ON UPDATE` у БД.
- `bot` досі на `@types/node` ^24.
- `AuthStore.revalidate('auth-error')` з відповіддю 200 не скидає прапорець `failed` — банер «Спробувати ще раз» може залишитись після попередньої 5xx.
- Google OAuth ще не перевірено на справжньому Google — перший вхід перевірити локально (localhost дозволений як redirect URI) або на staging.
