## Global Constraints

- Мова інтерфейсу й коментарів — українська; тексти лише через `uk.json`.
- Міграції — drizzle-kit, наступний номер після останнього в `backend/src/db/migrations/meta/_journal.json`.
- Тести: ніколи два процеси backend-тестів одночасно; shared збирати перед backend-тестами; prettier лише на змінених файлах.
- Не друкувати й не комітити секрети/`.env`; не змінювати ролі користувачів dev-БД.
- Коміти закінчуються `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.
- **Сповіщення:** користувач може «Прочитати все» (вже є), «Видалити всі прочитані» і видалити будь-яке сповіщення поштучно. Лише свої.
- **Відгуки (кнопка «Повідомити» з Плану 15):** на **dev** — як зараз (гості теж, 10/год з IP). На **prod** (і будь-якому не-dev, крім `local` для розробки — див. Task 2) — лише для користувачів, що ввійшли, **не більше 2 повідомлень на добу на користувача**; гостям кнопки немає, сервер — 401.
- Заглушку `jobs.purge` прибрати повністю; залишковий рядок у проді прибрати міграцією.
