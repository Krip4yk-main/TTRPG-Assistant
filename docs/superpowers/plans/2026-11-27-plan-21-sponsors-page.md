# План 21 — сторінка для спонсорів

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development. Steps use checkbox (`- [ ]`) syntax.

**Goal:** окрема публічна сторінка, куди можна дати посилання потенційним спонсорам. Поки на ній лише промо-картинка проєкту (з `.media/promo/`), пізніше додамо план витрат і список спонсорів.

**Spec:** запит власника в чаті 2026-11-27: «окрема сторінка для представлення спонсорів (поки пуста, там буде лежати промо)».

## Global Constraints

- Маршрут `/sponsors`, заголовок сторінки «Спонсорам» (`<title>` «Спонсорам — НРІ Асистент»). Доступна всім, зокрема гостям; без входу.
- Вміст зараз: промо-картинка (адаптивна: 1920×1080 і 3840×2160 як `srcset`, у WebP з PNG-запасним варіантом) з повноцінним `alt`, що переказує текст картинки (заголовок, функції для гравців і майстрів, «Шукаємо спонсорів», контакт). Під картинкою — один короткий рядок з контактом (`t.me/krip4yk`) як справжнє посилання, щоб його можна було натиснути й скопіювати. Нічого більше не вигадувати — сторінка свідомо мінімальна.
- Картинка — актив сайту (`frontend/src/assets/promo/`), не «медіа для рецензій»: виняток з правила «медіа лише в `.media/`» погоджено цим планом. Файли стиснути (WebP), розумний розмір (орієнтир ≤ 400 КБ для 1920).
- Посилання на сторінку: у футері поруч із «Про проєкт» — «Спонсорам». Більше ніде не рекламувати (без банерів і спливаючих вікон).
- SEO: сторінка в `sitemap.xml`; OG-теги (`og:title`, `og:description`, `og:image` = промо 1920×1080), щоб посилання гарно розгорталося в Telegram/соцмережах; індексується на prod, на dev — `noindex` як усе.
- Усі 10 дизайнів: сторінка використовує наявну розмітку сторінок («Про проєкт» як зразок), картинка не вилазить на 375 px (масштабується, без горизонтального скролу).
- Майбутнє (не робити зараз, лише не заважати): блок «План витрат на рік», список спонсорів. Структуру компонента зробити так, щоб їх можна було додати секціями.
- Тексти — `uk.json`; тести/typecheck/lint/build зелені; бюджет бандла не збільшувати (картинка — окремий ассет, маршрут — лінивий).
- Коміти з `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

## Review Focus

- Картинка не роздуває початковий бандл і не вантажиться на інших сторінках.
- `alt` справді передає зміст для незрячих користувачів.
- OG-картинка доступна за абсолютним URL на prod.
