# Ручне тестування MVP — чекліст

Коротко, без деталей. Для більшості пунктів потрібні 2–3 акаунти (майстер, гравець, другий гравець) і один з роллю адміна.

## 1. Вхід і акаунт
- [ ] Вхід через Telegram, Google, Discord (Discord — лише коли задано змінні; без них кнопки немає)
- [ ] Перший вхід → «Завершити профіль» (нік, часовий пояс), без цього далі не пускає
- [ ] Вихід, повторний вхід, повернення на сторінку, з якої пішов на вхід
- [ ] Акаунт: прив'язати / відв'язати спосіб входу; чужа ідентичність → помилка конфлікту
- [ ] Не можна відв'язати останній спосіб входу
- [ ] Видалення акаунта (з підтвердженням) → профіль «Акаунт видалено», ігри скасовані, заявки відкликані
- [ ] Банер «Доступна нова версія» після деплою

## 2. Профіль
- [ ] Редагування: нік, про себе, аватар, часовий пояс, улюблені системи, вікові обмеження
- [ ] Публічний профіль: історія ігор, рейтинг майстра (з 5+ оцінок), рейтинг по критеріях
- [ ] Чужий профіль: кнопки «Поскаржитися», «В чорний список»
- [ ] Чорний список: додати / прибрати; заблокований не бачить моїх ігор і не подається

## 3. Пошук ігор (головна для гравця й гостя)
- [ ] Фільтри: система, жанр, формат (кампанія/ваншот), онлайн/офлайн, місто, платна/безкоштовна, вік, дні/час
- [ ] Позначка «підходить за розкладом» (повністю / частково)
- [ ] Сортування, зокрема за рейтингом майстра
- [ ] Ігри 16+/18+/21+ приховані для гостя й молодших за позначку, з пропозицією увійти
- [ ] 16+ видно з 16-го дня народження (напередодні — обмежена картка)
- [ ] Стан фільтрів зберігається в URL (посилання відкривається з тими ж фільтрами)
- [ ] Гість бачить пошук і сторінку гри, але не може податися

## 4. Гра (майстер)
- [ ] Створення гри: усі поля, обкладинка, платна (ціна), кількість місць, вимоги, вікове обмеження
- [ ] Розклад: разова сесія, правило повторення для кампанії, перенесення, скасування сесії
- [ ] Редагування гри; зміна розкладу з нотатками до сесій (сесія скасовується, а не зникає)
- [ ] «Мої ігри» (головна для майстра): активні, завершені, скасовані
- [ ] Почати гру, завершити ваншот, відмітити сесію проведеною
- [ ] Скасувати гру → учасники отримують сповіщення

## 5. Заявки й учасники
- [ ] Гравець подає заявку (з повідомленням); «Мої заявки»; відкликати заявку
- [ ] Майстер: прийняти / відхилити; ліміт місць; повторна заявка після відхилення
- [ ] Панель учасників: вийти з гри, майстер виключає гравця, бан у грі
- [ ] Вільне місце після виходу → гра знову в наборі

## 6. Календар і розклад
- [ ] Редактор доступності (дні й години), застосовується до «підходить за розкладом»
- [ ] Календар: сесії моїх ігор, перехід до гри, RSVP (буду / не буду)
- [ ] Часові пояси: майстер і гравець у різних поясах бачать правильний час

## 7. Нотатки
- [ ] Нотатки до сесії (майстер), спільні нотатки гравців
- [ ] Нотатка до скасованої сесії лишається доступною

## 8. Сповіщення
- [ ] Дзвіночок: нові заявки, прийняття/відхилення, зміни гри, скасування, нагадування про сесію
- [ ] Позначити прочитаним, перейти за посиланням
- [ ] Налаштування: категорії × канали (застосунок / Telegram), вимкнення
- [ ] Telegram-бот: прив'язка, отримання сповіщень, команди
- [ ] Живе оновлення без перезавантаження (дві вкладки / два акаунти)

## 9. Оцінки
- [ ] Після сесії/ваншоту — запит на оцінку; сторінка «Оцінки» з чергою
- [ ] Оцінка майстра й гравців: зірки по критеріях, текст, «Відмовитись»
- [ ] Оцінка того, хто вийшов/виключений — одразу; вікно 30 днів від завершення гри
- [ ] Оцінювати можна лише тих, з ким грав хоча б одну сесію
- [ ] Рейтинг з'являється з 5 оцінок від різних людей/ігор і оновлюється пачками по 5

## 10. Модерація (для користувача)
- [ ] Скарга на людину (лише якщо перетинались) і на гру; скаржник отримує «Скаргу розглянуто»
- [ ] Санкції: банер про активну санкцію, «Мої санкції», пояснення при забороненій дії
- [ ] Апеляція на санкцію; апеляція на бан з екрана бану
- [ ] Ліміт 1 активної заявки, заборона платних ігор (подаватись / створювати)
- [ ] Глобальний бан: вхід заблоковано, ігри скасовані, профіль «Акаунт заблоковано»

## 11. «Мертві» ігри
- [ ] Гра без проведених сесій > 30 днів → нагадування майстру
- [ ] > 90 днів → зникає з пошуку, позначка в «Моїх іграх», блок створення нової гри з поясненням
- [ ] «Все ок» повертає гру; «Закрити» → скасована / завершена
- [ ] Накладання сесій двох ігор ≥ 3 разів за 4 тижні → позначка «підозріла» + сповіщення

## 12. Адмінка `/admin`
- [ ] Доступ: модератор / адмін / власник бачать свої вкладки; звичайний користувач — ні
- [ ] Скарги: відхилити / вжити заходів (санкція)
- [ ] Користувачі: пошук, картка (санкції, скарги, ролі), накласти / зняти санкцію, бан / розбан
- [ ] Апеляції: задовольнити / відхилити
- [ ] Відгуки: приховати текст, анулювати оцінку
- [ ] Ролі: призначити / зняти модератора й адміна; передача прав власника
- [ ] Журнал дій
- [ ] «Мертві ігри»: закрити / зняти позначку
- [ ] Каталог: додати систему, перейменувати, вимкнути (не пропонується в нових іграх)
- [ ] Щоденне зведення скарг о 09:00 (сповіщення персоналу)

## 13. Загальне
- [ ] Мобільна версія (вузький екран) — усі основні сторінки
- [ ] Сторінка «Про сервіс», SEO: sitemap, відкриття сторінки гри напряму
- [ ] Неіснуюча адреса → сторінка 404 «Сторінку не знайдено» (адреса в рядку лишається, `noindex`, кнопка «До пошуку ігор»)
