# Ручне тестування MVP — чекліст

Коротко, без деталей. Для більшості пунктів потрібні 2–3 акаунти (майстер, гравець, другий гравець) і один з роллю адміна.

## 1. Вхід і акаунт
- [ ] Вхід через Telegram, Google, Discord (Discord — лише коли задано змінні; без них кнопки немає)
- [ ] Перший вхід → «Завершити профіль» (нік, часовий пояс), без цього далі не пускає
- [ ] Вихід, повторний вхід, повернення на сторінку, з якої пішов на вхід
- [ ] Акаунт: прив'язати / відв'язати спосіб входу; чужа ідентичність → помилка конфлікту
- [ ] Не можна відв'язати останній спосіб входу
- [ ] Видалення акаунта (з підтвердженням) → профіль «Акаунт видалено», ігри скасовані, заявки відкликані
- [ ] Банер «Доступна нова версія» після деплою

## 2. Профіль
- [ ] Редагування: нік, про себе, аватар, часовий пояс, улюблені системи, вікові обмеження
- [ ] Публічний профіль: історія ігор, рейтинг майстра (з 5+ оцінок), рейтинг по критеріях
- [ ] Чужий профіль: кнопки «Поскаржитися», «В чорний список»
- [ ] Чорний список: додати / прибрати; заблокований не бачить моїх ігор і не подається

## 3. Пошук ігор (головна для гравця й гостя)
- [ ] Фільтри: система, жанр, формат (кампанія/ваншот), онлайн/офлайн, місто, платна/безкоштовна, вік, дні/час
- [ ] Позначка «підходить за розкладом» (повністю / частково)
- [ ] Сортування, зокрема за рейтингом майстра
- [ ] Ігри 16+/18+/21+ приховані для гостя й молодших за позначку, з пропозицією увійти
- [ ] 16+ видно з 16-го дня народження (напередодні — обмежена картка)
- [ ] Стан фільтрів зберігається в URL (посилання відкривається з тими ж фільтрами)
- [ ] Гість бачить пошук і сторінку гри, але не може податися

## 4. Гра (майстер)
- [ ] Створення гри: усі поля, обкладинка, платна (ціна), кількість місць, вимоги, вікове обмеження
- [ ] Розклад: разова сесія, правило повторення для кампанії, перенесення, скасування сесії
- [ ] Редагування гри; зміна розкладу з нотатками до сесій (сесія скасовується, а не зникає)
- [ ] «Мої ігри» (головна для майстра): активні, завершені, скасовані
- [ ] Почати гру, завершити ваншот, відмітити сесію проведеною
- [ ] Скасувати гру → учасники отримують сповіщення

## 5. Заявки й учасники
- [ ] Гравець подає заявку (з повідомленням); «Мої заявки»; відкликати заявку
- [ ] Майстер: прийняти / відхилити; ліміт місць; повторна заявка після відхилення
- [ ] Панель учасників: вийти з гри, майстер виключає гравця, бан у грі
- [ ] Вільне місце після виходу → гра знову в наборі

## 6. Календар і розклад
- [ ] Редактор доступності (дні й години), застосовується до «підходить за розкладом»
- [ ] Календар: сесії моїх ігор, перехід до гри, RSVP (буду / не буду)
- [ ] Часові пояси: майстер і гравець у різних поясах бачать правильний час

## 6а. Спільний час групи (План 12)
- [ ] Редактор доступності («Мій календар») пояснює: майстер бачить «може / не може / невідомо», а не самі слоти; порожній календар — «невідомо»
- [ ] Майстер кампейну: «Спільний час» → «Підібрати час» — регулярні (день + час) і разові варіанти на 4 тижні, у вашому поясі без назви поясу; для кожного учасника значок + текст (може / не може / невідомо, «N з 4 тижнів», «календар порожній»); учасник цієї кнопки не бачить; для завершеної чи скасованої гри кнопки немає
- [ ] Ніхто з групи не заповнив календар — підказка замість порожніх списків
- [ ] «Застосувати як розклад» відкриває звичний діалог розкладу з цим днем і часом; «Перенести сесію» — вибір сесії й перенесення (тривалість сесії зберігається); на паузі цих кнопок немає
- [ ] Позначити 2–6 варіантів → «Створити голосування з варіантів» або «Створити голосування» вручну (день тижня + час чи дата + час у поясі гри з підказкою у вашому поясі), строк 12 год – 14 днів; разові варіанти — пізніше за кінець голосування; більше трьох відкритих голосувань — зрозуміла помилка
- [ ] Учасники отримують сповіщення «шукає зручний час» (сайт і Telegram з кнопками «можу / не можу / якщо треба» на кожен варіант; натиснута кнопка позначається ✔️, відповідь можна змінити)
- [ ] Учасник відповідає на сторінці гри (посилання зі сповіщення фокусує голосування); бачить підсумки й хто вже відповів; змінює відповідь до закриття; після дедлайну — «голосування вже завершено»
- [ ] Відповіли всі — голосування закривається саме, майстру сповіщення; дедлайн — те саме; «Завершити зараз» майстром — з підтвердженням, без сповіщення собі
- [ ] Підсумок: переможець підсвічений; «Застосувати» (або будь-який інший варіант): регулярний — новий розклад (кілька днів у грі → вибір «замінити» чи «додати день» з поясненням про один час початку; вибір отримує фокус), разовий — перенесення сесії чи нова сесія (учасникам сповіщення про нову сесію); сесії вже немає — пропозиція «створити як нову сесію»; на паузі застосувати не можна
- [ ] Друга вкладка / інший учасник: банер «Є оновлення» оновлює голосування без перезавантаження
- [ ] Учасник ставить «не буду» → через ~5 хв майстру одне сповіщення (кілька учасників разом — «X та ще N»; передумав за 5 хв — сповіщення немає; сесія за ≤ 2 год — одразу); посилання відкриває «Інший час для сесії»: до 3 варіантів у ±3 доби з тим, хто може, і «Перенести сюди» одним кліком; сесія вже минула чи перенесена — пояснення
- [ ] «Інший час» біля майбутньої сесії в списку сесій (майстер)
- [ ] Учасник кампейну з порожнім календарем через добу після вступу отримує одне нагадування заповнити календар (більше ніколи)
- [ ] «Мій календар» → «Імпорт календаря»: підказка, де взяти приватне iCal-посилання (Google / Apple / Outlook); http:// чи внутрішня адреса — зрозуміла помилка; після підключення видно лише хост, час оновлення й кількість подій; зайнятий час враховується в підборі
- [ ] «Оновити зараз» — не частіше ніж раз на 5 хв (кнопка вимкнена з підказкою); сервер зайнятий — «спробуйте за пів хвилини»; дуже довга серія — позначка «частину подій пропущено»
- [ ] Посилання перестало працювати 5 разів поспіль — сповіщення, статус «зламано» з поясненням; повторне підключення чи вдале оновлення відновлює; «Відключити» (з підтвердженням) видаляє посилання й дані
- [ ] Налаштування сповіщень: «Розклад» можна вимкнути на сайті (тоді й у Telegram) і окремо в Telegram
- [ ] Усе вище — у 375px і в дизайнах (світлий «Сонячний сад», темні сцени)

## 7. Нотатки
- [ ] Нотатки до сесії (майстер), спільні нотатки гравців
- [ ] Нотатка до скасованої сесії лишається доступною

## 8. Сповіщення
- [ ] Дзвіночок: нові заявки, прийняття/відхилення, зміни гри, скасування, нагадування про сесію
- [ ] Позначити прочитаним, перейти за посиланням
- [ ] Налаштування: категорії × канали (застосунок / Telegram), вимкнення; «Розклад» вимикається й на сайті
- [ ] Telegram-бот: прив'язка, отримання сповіщень, команди
- [ ] Живе оновлення без перезавантаження (дві вкладки / два акаунти)

## 9. Оцінки
- [ ] Після сесії/ваншоту — запит на оцінку; сторінка «Оцінки» з чергою
- [ ] Оцінка майстра й гравців: зірки по критеріях, текст, «Відмовитись»
- [ ] Оцінка того, хто вийшов/виключений — одразу; вікно 30 днів від завершення гри
- [ ] Оцінювати можна лише тих, з ким грав хоча б одну сесію
- [ ] Рейтинг з'являється з 5 оцінок від різних людей/ігор і оновлюється пачками по 5

## 10. Модерація (для користувача)
- [ ] Скарга на людину (лише якщо перетинались) і на гру; скаржник отримує «Скаргу розглянуто»
- [ ] Санкції: банер про активну санкцію, «Мої санкції», пояснення при забороненій дії
- [ ] Апеляція на санкцію; апеляція на бан з екрана бану
- [ ] Ліміт 1 активної заявки, заборона платних ігор (подаватись / створювати)
- [ ] Глобальний бан: вхід заблоковано, ігри скасовані, профіль «Акаунт заблоковано»

## 11. «Мертві» ігри
- [ ] Гра без проведених сесій > 30 днів → нагадування майстру
- [ ] > 90 днів → зникає з пошуку, позначка в «Моїх іграх», блок створення нової гри з поясненням
- [ ] «Все ок» повертає гру; «Закрити» → скасована / завершена
- [ ] Накладання сесій двох ігор ≥ 3 разів за 4 тижні → позначка «підозріла» + сповіщення

## 11а. Пауза кампейну й донабір
- [ ] Майстер кампейну (набір чи гра триває): «Поставити на паузу» на сторінці гри чи в «Моїх іграх» → причина (відпустка / хвороба / навчання чи робота / інше, обов'язкова) і пояснення до 300 символів з лічильником; ваншоту, чернетці й не-майстру кнопки немає
- [ ] На паузі: бейдж «На паузі» на сторінці гри, у «Моїх іграх» і в профілях; гра зникла з пошуку; кнопки заявки немає, пояснення «Кампейн на паузі — заявки зараз не приймаються» (і для гостя)
- [ ] Панель «Кампейн на паузі»: з якого часу (у вашому поясі, без назви поясу), причина й пояснення — бачать майстер і учасники, сторонні — лише сам факт паузи
- [ ] Майбутні сесії скасовано з причиною «кампейн на паузі», вони зникли з календаря зайнятості; минулі сесії, нотатки й склад — без змін; учасники отримали сповіщення (сайт і Telegram за налаштуваннями)
- [ ] «Відновити» / «Оголосити донабір»: дата й час першої сесії (у поясі гри; минула дата чи день поза правилом — помилка біля поля); далі розклад за правилом; донабір — гра знову в пошуку й приймає заявки; учасникам — сповіщення (з донабором — окремий текст)
- [ ] Пауза з набору й відновлення з меншою за мінімум кількістю учасників — попередження в діалозі й після відновлення
- [ ] На паузі можна редагувати назву, опис, посилання, обкладинку тощо; поля розкладу у формі вимкнені з підказкою «розклад змінюється при відновленні»
- [ ] «Завершити кампейн» і «Скасувати гру» доступні з паузи (на панелі й у «Моїх іграх»), з тим самим підтвердженням
- [ ] Учасник може вийти з гри на паузі; майстер — виключити чи заблокувати учасника; затвердити заявку на паузі не можна (зрозуміла помилка)
- [ ] Детектор «мертвих» ігор не позначає кампейн на паузі; одразу після відновлення гра не «мертва»
- [ ] Пауза понад 90 днів → нагадування майстру (потім раз на 30 днів) з трьома посиланнями: «Відновити», «Оголосити донабір», «Завершити кампейн» — відкривають відповідний діалог на сторінці гри; якщо кампейн уже не на паузі — коротке пояснення

## 12. Адмінка `/admin`
- [ ] Доступ: модератор / адмін / власник бачать свої вкладки; звичайний користувач — ні
- [ ] Скарги: відхилити / вжити заходів (санкція)
- [ ] Користувачі: пошук, картка (санкції, скарги, ролі), накласти / зняти санкцію, бан / розбан
- [ ] Апеляції: задовольнити / відхилити
- [ ] Відгуки: приховати текст, анулювати оцінку
- [ ] Ролі: призначити / зняти модератора й адміна; передача прав власника
- [ ] Журнал дій
- [ ] «Мертві ігри»: закрити / зняти позначку
- [ ] Каталог: додати систему, перейменувати, вимкнути (не пропонується в нових іграх)
- [ ] Щоденне зведення скарг о 09:00 (сповіщення персоналу)

## 13. Загальне
- [ ] Мобільна версія (вузький екран) — усі основні сторінки
- [ ] Сторінка «Про сервіс», SEO: sitemap, відкриття сторінки гри напряму
- [ ] Неіснуюча адреса → сторінка 404 «Сторінку не знайдено» (адреса в рядку лишається, `noindex`, кнопка «До пошуку ігор»)

## 14. Дизайни на вибір
- [ ] «Вигляд» у налаштуваннях акаунта — десять дизайнів для будь-якого користувача (не лише персоналу): «Дошка оголошень», «Неонові вивіски», «Голо-ринок», «Нічне місто», «Підземелля», «Готичний морок», «Магіпанк», «Латунь і пара», «Сонячний сад» (світлий), «Мальоване місто»; «Класичного» більше немає
- [ ] Сітка мініатюр «Вигляду» на 375px не ламається (без горизонтального прокручування); мініатюри — реальні скріншоти пошуку
- [ ] Перемикання дизайну — без кадру без стилів і без «запасного» шрифту в заголовку-вивісці (зокрема літера «і» у «Знайдіть»): старий дизайн лишається, доки не завантажилися бандл і шрифт заголовка нового
- [ ] Власні налаштування дизайну видно лише в їхньому дизайні: «Дошка оголошень» — «Анімація відривання листка»; решта дев'ять — «Фірмові анімації дизайну» (одна спільна назва; вимкнено — жодної фірмової анімації в цьому дизайні)
- [ ] Фірмова анімація — одна на дизайн, ≤ 1.6 с («Неонові вивіски», «Латунь і пара», «Сонячний сад» — 2.5–2.6 с), лише після успіху дії (помилка — без анімації); `prefers-reduced-motion: reduce` — жодної (ні відривання, ні фірмових):
  - [ ] «Дошка оголошень»: картка при відкритті гри «відривається» від шпильки
  - [ ] «Заявку подано» (після відповіді сервера, діалог заявки): «Магіпанк» — форма складається в конверт під сургучем і відлітає; «Неонові вивіски» — вивіска «ЗАЯВКУ ПОДАНО» спалахує трубками; «Нічне місто» — імпульс біжить силовою шиною, табличка «Заявку передано»; «Латунь і пара» — телеграфна стрічка «ЗАЯВКУ ПОДАНО STOP» і штамп «ВІДПРАВЛЕНО»; «Сонячний сад» — пакетик насіння, паросток і бирка «Заявку подано»; «Мальоване місто» — пензель виписує тег «Я в грі!» з патьоками
  - [ ] Під час анімації «заявку подано» діалог не закривається (ні Esc, ні клік поза ним, ні «Скасувати»); після неї закривається сам, заявка подана
  - [ ] «Відкриття гри» — анімація грає на самій картці (пошук, профіль), і лише після неї відкривається сторінка гри; пряма адреса, перезавантаження, «Назад»/«Вперед», клік з Ctrl/середньою кнопкою — без анімації: «Голо-ринок» — картка згортається лінією у свій проєктор, промінь угору; «Підземелля» — ґрати падають на картку й ривками піднімаються; пішли зі сторінки посеред анімації — гра не відкривається
  - [ ] «Готичний морок», «вас прийнято»: непрочитане сповіщення в панелі дзвіночка — сургучна печатка на рядку; один раз на сповіщення (повторне відкриття панелі, перезавантаження — без анімації); лише коли рядок видно у відкритій панелі (прокрутили до нього — тоді й грає); закрили панель — анімація зникає
- [ ] Синхронізація дизайну між сесіями: змінили дизайн чи налаштування вигляду в одній вкладці/на одному пристрої — інші відкриті сесії цього акаунта перемикаються самі, без перезавантаження
- [ ] Вибір застосовується одразу, без перезавантаження, і зберігається після перезавантаження та на іншому пристрої

## 15. Надійність і дрібні покращення (План 13)
- [ ] `/api/health/live` — завжди 200, поки процес живий; `/api/health` — 200 з `db`, `redis`, `worker` = ok; зупинили MySQL чи Redis — 503 з `down`; воркер не просувався понад 5 хв — 503 `worker: stale`; без cookie у відповіді

## 16. Приблизний час, чернетки без дати, аватари, dev-середовище (План 15)
- [ ] Заявки: після відхилення повторна заявка — лише через 1 год (повідомлення з часом, коли можна); після відкликання — як було, 10 хв
- [ ] Чернетка без дати: у формі дату старту можна очистити й зберегти чернетку; картка й деталі — «Дату ще не визначено»; «Опублікувати» без дати — зрозуміла помилка, гра лишається чернеткою; не-чернетку без дати не зберегти; «Створити копію» — чернетка без дати
- [ ] Приблизний час гри: у формі «Точний час / Приблизно» → «з» і «до» (крок 30 хв, до > з, максимум 12 год); сесії з правила показують «18:00–21:00 · час уточнюється»; зміна вікна в грі змінює майбутні неперенесені сесії
- [ ] Приблизний час сесії: перенесення сесії на вікно й назад на точний час; учасникам — сповіщення з вікном або точним часом; нагадування учасникам — від початку вікна; ICS — подія від початку вікна до кінця вікна + тривалість, у назві «(час уточнюється)»
- [ ] «Уточнити час» (майстер): діалог зі стартами кожні 30 хв у вікні й кількістю вільних (хто не може); вибір — точний час; уточнити можна й у минуле, але лише всередині вікна; майстру — сповіщення «уточни час» за 24 год до початку вікна, один раз (після перенесення — знову)
- [ ] Обмеження: «Почати гру», поки найближча сесія з вікном, — пояснення й кнопка «Уточнити час»; «Завершити сесію» з вікном — те саме; «Завершити гру» ваншота з вікном — те саме; закриття «мертвого» ваншота (майстром чи модератором) — проходить: вікно, що вже почалося, — сесія проведена, майбутнє — скасована
- [ ] Точні варіанти (голосування за час, «Інші варіанти» сесії, «Спільний час» → «Перенести сесію») переносять сесію з вікном на точний час — «час уточнюється» зникає
- [ ] Аватар (профіль): варіанти Google / Discord / Telegram — лише прив'язані з аватаром, з прев'ю; «Власне посилання» — перевірка (http://, не картинка, завелика — помилка з причиною); «Без аватара» — заглушка; посилання, що перестало відкриватись, — заглушка; новий вхід провайдером оновлює його прев'ю
- [ ] Dev-середовище (`DEPLOY_ENV=dev`): банер «Тестове середовище» на кожній сторінці; відповіді з `X-Robots-Tag: noindex, nofollow`, `robots.txt` — `Disallow: /`; на prod — ні банера, ні noindex; бекапи на dev вимкнені без помилок у лозі
- [ ] Кнопка «Повідомити» (на dev — усім, на prod — лише тим, хто ввійшов, див. наступний пункт): унизу справа на кожній сторінці, не перекриває банер, з клавіатури, видима в усіх дизайнах; тип + текст (до 4000), «Додамо: …» показує контекст (адреса без токенів і кодів, дизайн, розмір вікна, браузер); на dev гість теж може, 11-й звіт за годину з IP — відмова (на prod правила — у наступному пункті); власнику — сповіщення на сайті; `/admin/tester-reports` (адмін і власник) — список, фільтр «нові / опрацьовані», «Опрацьовано»; адмінка `/admin/tester-reports` — у всіх середовищах

## 17. Безпека гри (План 17)
- [ ] Форма гри: секція «Безпека гри» необов'язкова й типово згорнута; відкривається з клавіатури; порожня — гра зберігається без змін, нічого не дописується в чернетку автоматично
- [ ] «Межі» й «Завіси»: теми з каталогу попереджень і власні (до 10, по 100 символів, без дублів); одна тема не може бути одночасно межею й завісою; чекліст «Інструменти безпеки» (X-Card, зміна сцени тощо) з поясненням кожного
- [ ] Сторінка гри: блок «Безпека гри» з'являється лише коли щось заповнено; межі, завіси й інструменти — окремими списками; гра без безпеки — блока немає
- [ ] Пошук: фільтр «З інструментами безпеки» залишає ігри, де є інструмент, межа чи завіса; поєднується з іншими фільтрами, курсор не ламається
- [ ] Діалог заявки: показує підсумок безпеки гри (межі, завіси, інструменти) і блок «Ваші межі» з кнопкою «Підставити мої межі» (порожні рядки заповнюються першими, повідомляється, скільки підставлено); заявку можна подати й без них
- [ ] «Мої межі» у профілі: список до 10 пунктів, зберігається; приватне — не видно в публічному профілі, у списку учасників гри й у пошуку; бачить лише власник (і підставляється в заявку за його дією)
- [ ] X-Card: у вікні сесії учасник гри (не майстер, не стороній) натискає X-Card; майстру приходить анонімне сповіщення (без імені того, хто натиснув) на сайті й у Telegram; не частіше 1 разу на 5 хв (повторне — зрозуміла відмова); у тихі години Telegram приходить одразу й зі звуком
